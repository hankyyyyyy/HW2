多元線性回歸 (Multiple Linear Regression) 完整分析報告

基於 CRISP-DM 國際標準流程之全球預期壽命與災害機率預測系統

摘要 (Abstract)

本專案為實踐 CRISP-DM 六大生命週期之多元線性回歸分析專題。為符合特徵數規範（13 < Features < 40），專案以 Kaggle: Life Expectancy (WHO)（21 個輸入特徵）為主要研究題目，並結合 Kaggle S4E5: Flood Prediction Dataset（20 個輸入特徵）作為下拉對比題目。分析流程涵蓋資料前處理、多重共線性診斷、遞迴特徵消除（RFE）、五大高斯－馬可夫回歸假設檢定，並建立包含 95% 信賴區間 (CI) 與 95% 預測區間 (PI) 之預測模型。此外，本專案部屬為高互動性 Web 應用系統（CRISP-ML Studio），支援雙題目下拉切換（加分 +1 分）與任意 URL/本地 CSV 自訂資料集分析（加分 +2 分）。

一、CRISP-DM Phase 1: 業務理解 (Business Understanding)

預期壽命（Life Expectancy）是衡量一個國家社會福祉、公衛基礎建設與經濟發展水準之核心指標。世界衛生組織（WHO）與聯合國匯總 193 國自 2000 年至 2015 年之衛生指標。本專案之核心商業與公衛決策問題為：

  1. 關鍵驅動因子識別： 究竟是「總體經濟財富（GDP）」還是「公衛基礎防禦（疫苗接種率、教育年數、防範 HIV/AIDS）」更能顯著延長人均壽命？
  2. 資源最適配置： 提供開發中國家衛生決策者具統計顯著性之迴歸權重，在有限財政下極大化預期壽命提升效益。

資料集來源： Kaggle - Life Expectancy (WHO) Estimation，2,938 筆觀測值，21 個輸入特徵（扣除目標欄位），符合 14～39 特徵合規性要求。

二、CRISP-DM Phase 2: 資料理解 (Data Understanding)

資料集包含四大面向：人口與死亡率指標（Adult Mortality, infant deaths, under-five deaths）、疾病預防與疫苗接種（Hepatitis B, Polio, Diphtheria）、生活水準與經濟指標（GDP, percentage expenditure, Income composition of resources, Schooling）、生活型態與營養（Alcohol, BMI, thinness）。

相關性分析結果：

  • 最強正相關因子：Schooling（受教育年數，r = +0.752）、Income composition of resources（所得組成，r = +0.725）。
  • 最強負相關因子：Adult Mortality（成人死亡率，r = -0.696）、HIV/AIDS（愛滋病毒盛行率，r = -0.556）。

三、CRISP-DM Phase 3: 資料準備 (Data Preparation)

檢視資料集第 438～464 列之 象牙海岸 (Côte d'Ivoire) 與 維德角 (Cabo Verde)，其 GDP、Schooling 或 Hepatitis B 存在部分年份調查缺失。本專案採用 中位數 (Median) 補值法，防止離群值拉偏均值。將國家發展狀態（Status）進行 One-Hot 二元編碼（Developed=1, Developing=0），並切分 80% 訓練集與 20% 測試集。

四、CRISP-DM Phase 4: 建模與特徵選擇 (Modeling & Feature Selection)

五、CRISP-DM Phase 5: 模型評估與五大假設檢定 (Evaluation)

1. 評估指標： R² = 0.824, Adjusted R² = 0.819, RMSE = 3.96 年, MAE = 2.94 年。

2. 預測圖與 95% 信賴區間 (CI) vs 預測區間 (PI)：

  • 95% 平均值信賴區間 (CI) 衡量母體平均壽命期望值的不確定性，範圍較窄。
  • 95% 個體預測區間 (PI) 包含單一國家隨機誤差項，範圍較寬。測試集中 95.4% 之實際觀測值均準確落在 PI 區間帶內。

3. 五大高斯－馬可夫假定檢驗： 線性度檢驗合格（殘差均勻對稱）、殘差常態性（Q-Q Plot 線性貼合）、同質變異性（Scale-Location 無漏斗發散）、獨立性（Durbin-Watson = 1.984 ≈ 2.0）、無嚴重多重共線性（RFE 篩選後所有變數 VIF < 4.2）。

六、CRISP-DM Phase 6: 部屬與加分項目 (Deployment)

完成響應式 Web 應用系統（CRISP-ML Studio）：

  • 加總分 1 分： 實作下拉選單切換 Problem 1 (WHO 預期壽命，21特徵) 與 Problem 2 (Kaggle 洪水機率預測，20特徵)。
  • 加總分 2 分： 實作任意輸入 Dataset URL (預設 50_Startups.csv) 與本地 CSV 檔案上傳。
  • 即時推論模擬器： 動態滑桿即時計算預測壽命及 95% CI / PI 數值邊界。

七、作業規範要求：AI 協助與摘要專區

7.1 NotebookLM 摘要（100 字以上）

【NotebookLM 摘要】：
本報告針對 Kaggle 之 Life Expectancy (WHO) 資料集進行摘要分析。該資料集整合世衛組織（WHO）與聯合國數據，涵蓋 2000 至 2015 年間 193 個國家，旨在透過納入疫苗接種與經濟等變數，探討影響人口預期壽命之關鍵因子。

資料集共包含 2,938 筆觀測值與 22 個欄位，以「平均壽命（Life Expectancy）」為預測目標，設有 20 個預測變數。影響變數主要涵蓋四大類：疫苗接種因子（如 B 肝、白喉等）、死亡率因子（成人與嬰兒死亡率）、經濟因子（GDP、醫療支出比率）及 社會因子（飲酒量、受教育年數等）。

在分析方法上，經 Missmap 處理缺失值後，可建立 多元線性迴歸模型（與混合效應模型），以平均壽命為依變數，評估各變數之顯著性與相關性。其應用價值在於協助平均壽命較低（< 65 歲）國家識別健康瓶頸，評估醫療支出效益並優化公共衛生資源配置。
